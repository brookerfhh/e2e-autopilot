# 基础知识

> Cookbook / ItemV2 的基础概念：对象类型、常用字段。流程见 [流程](./流程.md)。

## 入口 / 环境

- Item 模块入口：`/ItemV2`（不是 `/items`）。默认指向 **QA**（`APP_URL` 可切）。
- Item 带**版本**：新建出来是 **DRAFT（草稿）**，配置齐全后才能 **Publish（发布）**；发布近乎不可逆。

## 对象类型（Object）

| 类型 | 新建方式 | 特点 |
|------|----------|------|
| **Menu / Food** | Create New → Menu → Food（两步） | 可加组件、可删、可发布 |
| **HDR Consumable** | Create New → HDR Consumable（一步） | 有额外必填（State / Unit）；**不能删**；发布前需填 Out of Stock Name |

**BOM / Component**：一个 Menu/Food item 通过 BOM（配料表）挂载若干 **Component（组件）**，组件本身是另一个已存在的 item（按名字或编号搜到并选中）。有了组件后才会出现 Packaged SKU。

## 常用字段

| 字段 | 位置 | 说明 |
|------|------|------|
| `* Item Name` | 新建弹窗 | 必填，唯一名 |
| `* State` / `* Unit Used in BOM` | 新建弹窗（仅 HDR） | HDR 必填，如 Thawed / g |
| **Concept** | Item Information 卡片 | 多选，item 归属的概念 / 品牌线（如 `2PRs Fred's`） |
| **Service Setting Reviewed** | Service Setting 弹窗 | 开关 |
| **Nutrition Reviewed** | 营养编辑页 | 开关；打开前需先录营养值 |
| **Packaged SKU** | Packaged SKUs 区块 | 三个必填下拉（Service Location / Smallware Tool / Pan Size，可选 N/A）；需 item 已有组件 |
| **Out of Stock Name** | HDR 的 Item Information | HDR 发布前必填 |
| **Usage** | 加组件对话框 | 组件用量，默认 1 |
