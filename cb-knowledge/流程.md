# 流程

> Cookbook / ItemV2 常见业务流程，一句话版。字段和对象含义见 [基础知识](./基础知识.md)。

## 造一个可发布的 Menu Item

**建草稿 Menu Item → 加一个 Component → 配 Concept / Service Setting / Nutrition / Packaged SKU → Publish。**

（顺序有依赖：先加组件才会出现 Packaged SKU；Nutrition Reviewed 要在录完营养值后最后打开。对应组合 flow：`buildFullMenuItem`（用已有组件）/ `assembleFullMenuItem`（连组件也现造）。）

## 其他流程（一句话）

- **建 → 搜 → 删（自清理）**：建个 item，按名字搜到，再删掉，跑完不留垃圾 → `createSearchDeleteItem`。
- **给已有 item 加组件**：进详情页 BOM 编辑器，搜到组件、填 Usage、保存 → `addComponentToItem`。
- **发布 HDR Consumable**：先填必填的 Out of Stock Name，再 Publish → `publishHdrConsumable`。

> flow 的完整参数 / 返回值以 [`flows/FLOWS.md`](../flows/FLOWS.md) 为准；运行时用自然语言告诉 agent 意图即可（如「造一个 Menu Item，把 4000470 作为组件」）。
